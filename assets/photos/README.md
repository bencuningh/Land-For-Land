# Photos

Drop real photos in here with these exact filenames — each `<img data-photo="...">`
in `index.html` already points at them, so no code changes are needed once
the files exist. Until then, each frame shows a graceful placeholder.

| Filename | Chapter |
|---|---|
| `citizen-capital.jpg` | Analyst, Citizen Capital |
| `redesk.jpg` | Co-building Redesk, alongside ESSEC |
| `joko.jpg` | Account Executive, Joko |
| `sport.jpg` | Sport, always |
| `phoenix-races.jpg` | Founder, Phoenix Races |

Frames are portrait, `4:5` aspect ratio, `object-fit: cover` — a vertical or
square photo crops cleanly; a wide landscape will lose its edges. No stock
or AI-generated imagery.
